# Source Code

This directory contains the main Python source code for the DigitReader application.

## Main File

- `main.py`: Main application entry point, including the graphical user interface, image preprocessing, digit segmentation, language detection, and digit recognition.

## Model Directory

The trained deep learning models are stored separately in the project's `models/` directory.

## Running the Application

From the project root directory, run:

```bash
python src/main.py
```

Make sure the required dependencies are installed and the trained model files are available in the `models/` directory.
